# sunicONEorTWO-wobpurt original readme.md
This is a port of RSDKv4 to the web, allowing you to play Sonic 1 and Sonic 2's respective data.rsdk's on the web.

This is just an attempt, and I may or may not update this to my liking, or to fix bugs.

YOU NEED THE "data.rsdk" OF EITHER SONIC 1 OR 2 IN ORDER TO RUN THIS! 

# NOTE
this is testing grounds, and should not be used as a playing ground as bugs are expected.
